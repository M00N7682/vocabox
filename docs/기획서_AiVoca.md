## 1. 프로젝트 개요

### 1.1 배경 및 문제 정의

현재 많은 소규모 영어학원에서는 학생 단어 시험 관리를 **엑셀 VBA 기반**으로 운영하고 있다.

**현재 운영 방식 (AS-IS):**

- 엑셀에 단어장을 수동으로 등록 (기존에 만들어 둔 VBA 매크로 활용)
- 학생을 등록하면 해당 학생용 시험지를 엑셀로 자동 생성
- 생성된 시험지를 프린트해서 학생에게 배부
- 시험 결과(점수)는 별도로 수기 기록하거나 엑셀에 직접 입력

**이 방식의 한계:**

| 문제 | 상세 설명 |
|------|-----------|
| 데이터 로컬 종속 | 특정 PC에서만 접근 가능, 백업이 취약함 |
| 동시 접근 불가 | 여러 선생님이 동시에 작업할 수 없음 |
| 출력 이력 없음 | 어떤 학생에게 언제 어떤 시험지를 출력했는지 기록이 남지 않음 |
| 점수 관리 비효율 | 날짜별 점수를 수작업으로 기록, 통계/리포트 생성이 어려움 |
| 스케줄 관리 부재 | 어떤 학생이 언제 어떤 단어장을 공부해야 하는지 체계적 관리 안됨 |
| 학원 간 재사용 불가 | 각 학원마다 동일한 시스템을 처음부터 다시 구축해야 함 |

### 1.2 프로젝트 목표

**TO-BE: AiVoca 웹 서비스**

1. 엑셀 VBA를 대체하는 **웹 기반 학원 관리 시스템** 구축
2. 처음부터 **멀티테넌트(SaaS) 구조**로 설계하여 여러 학원에 서비스 제공 가능
3. 우리 학원에서 먼저 사용하여 **포트폴리오**로 활용, 이후 다른 학원 대상 영업

### 1.3 핵심 가치 비교

| 항목 | 기존 (엑셀 VBA) | AiVoca |
|------|-----------------|--------|
| 접근성 | 로컬 PC에서만 사용 | 어디서든 웹 브라우저로 접근 |
| 단어장 관리 | 엑셀에 수동 입력 | CSV 업로드로 일괄 등록 |
| 시험지 출력 | 기록 없이 프린트만 | 출력 이력 자동 기록 |
| 점수 관리 | 수기 기록 / 별도 엑셀 | 날짜별 점수 시스템 자동 관리 |
| 통계/리포트 | 직접 만들어야 함 | 자동 그래프/리포트 제공 |
| 확장성 | 학원마다 재구축 | 가입만 하면 바로 사용 (SaaS) |
| 과제 스케줄 | 관리 불가 | 캘린더 기반 체계적 관리 |

### 1.4 서비스명

- **AiVoca** (AI + Vocabulary)
- 추후 AI 기반 학습 추천, 자동 오답노트 등으로 확장 가능성을 열어둔 네이밍

## 2. 사용자 정의

### 2.1 사용자 유형 (MVP / Phase 1)

| 역할 | 설명 | 주요 권한 |
|------|------|-----------|
| **학원 관리자 (원장)** | 학원을 등록하고 전체 관리 권한 보유 | 학원 설정, 선생님 계정 초대/관리, 전체 데이터 접근, 삭제 권한 |
| **선생님** | 관리자가 초대한 교사 계정 | 학생 관리, 단어장 관리, 시험지 출력, 점수 입력, 스케줄 관리 |

> **참고:** 학생/학부모 로그인은 Phase 1에서 제외. 향후 확장 계획에 포함.

### 2.2 사용자 스토리 (User Stories)

#### 관리자(원장) 스토리

| ID | 스토리 | 우선순위 |
|----|--------|----------|
| A-01 | 원장은 이메일/비밀번호로 회원가입하고 학원을 등록할 수 있다 | 필수 |
| A-02 | 원장은 학원 기본 정보(학원명, 연락처, 로고)를 설정/수정할 수 있다 | 필수 |
| A-03 | 원장은 선생님 이메일로 초대 링크를 보내서 교사 계정을 추가할 수 있다 | 필수 |
| A-04 | 원장은 선생님 계정을 비활성화/삭제할 수 있다 | 필수 |
| A-05 | 원장은 전체 학생, 반, 단어장, 점수, 스케줄 데이터를 조회할 수 있다 | 필수 |

#### 선생님 스토리

| ID | 스토리 | 우선순위 |
|----|--------|----------|
| T-01 | 선생님은 새 학생을 등록하고 기본 정보를 입력할 수 있다 | 필수 |
| T-02 | 선생님은 반(클래스)을 만들고 학생을 배정할 수 있다 | 필수 |
| T-03 | 선생님은 CSV 파일로 단어장을 일괄 등록할 수 있다 | 필수 |
| T-04 | 선생님은 단어장 내 단어를 개별적으로 추가/수정/삭제할 수 있다 | 필수 |
| T-05 | 선생님은 특정 학생 + 단어장 조합으로 시험지를 생성하고 인쇄할 수 있다 | 핵심 |
| T-06 | 선생님은 시험지를 영→한, 한→영 두 가지 유형으로 생성할 수 있다 | 핵심 |
| T-07 | 선생님은 시험지 출제 시 랜덤 셔플, 범위 지정, 문항 수 제한 옵션을 설정할 수 있다 | 핵심 |
| T-08 | 선생님은 시험 후 학생의 점수를 날짜별로 입력할 수 있다 | 필수 |
| T-09 | 선생님은 반 단위로 여러 학생의 점수를 한꺼번에 입력할 수 있다 | 필수 |
| T-10 | 선생님은 학생에게 과제 스케줄(어떤 날짜에 어떤 단어장)을 배정할 수 있다 | 필수 |
| T-11 | 선생님은 캘린더 뷰에서 과제 스케줄 현황을 한눈에 확인할 수 있다 | 필수 |
| T-12 | 선생님은 학생별 점수 추이를 그래프로 확인할 수 있다 | 필수 |
| T-13 | 선생님은 대시보드에서 오늘 할 일과 최근 현황을 한눈에 볼 수 있다 | 필수 |

## 3. 기능 명세 (Feature Spec)

### 3.1 인증 및 학원 등록

#### 3.1.1 학원 가입 플로우

```
[랜딩 페이지 방문]
    ↓
[회원가입 클릭]
    ↓
[Step 1: 계정 정보 입력]
  - 이메일 (필수)
  - 비밀번호 (필수, 8자 이상)
  - 비밀번호 확인
    ↓
[Step 2: 학원 정보 입력]
  - 학원명 (필수)
  - 학원 연락처 (선택)
  - 관리자 이름 (필수)
    ↓
[이메일 인증 (선택사항, 추후 도입 가능)]
    ↓
[학원 생성 + 관리자 계정 연결]
    ↓
[대시보드로 자동 이동]
```

**세부 사항:**
- Supabase Auth 기반 이메일/비밀번호 인증
- 가입 시 `academies` 테이블에 학원 레코드 생성
- 학원 slug 자동 생성 (학원명 기반, 예: `해피영어학원` → `happy-english-1234`)
- 가입 완료 후 대시보드로 자동 리다이렉트
- 로그인 시 소속 학원(academy_id) 자동 인식

#### 3.1.2 로그인

- 이메일 + 비밀번호 입력
- 비밀번호 찾기 (이메일로 재설정 링크 발송)
- 로그인 유지 (Supabase 세션 기반)

#### 3.1.3 선생님 초대

```
[관리자: 설정 > 선생님 관리]
    ↓
[초대하기 버튼 클릭]
    ↓
[선생님 이메일 입력]
    ↓
[초대 이메일 발송 (초대 링크 포함)]
    ↓
[선생님: 초대 링크 클릭]
    ↓
[비밀번호 설정 + 이름 입력]
    ↓
[해당 학원에 자동 배정]
    ↓
[대시보드로 이동]
```

### 3.2 학생 관리

#### 3.2.1 학생 등록 항목

| 필드 | 데이터 타입 | 필수 여부 | 설명 | 비고 |
|------|------------|-----------|------|------|
| 이름 | text | **필수** | 학생 한글 이름 | |
| 영어 이름 | text | 선택 | 영어 수업에서 사용하는 이름 | |
| 연락처 | text | 선택 | 학생 전화번호 | 010-XXXX-XXXX 형태 |
| 학부모 연락처 | text | 선택 | 학부모 전화번호 | |
| 학교 | text | 선택 | 재학 중인 학교명 | |
| 학년 | text | 선택 | 학년 정보 | 자유 입력 (예: 중2, 고1) |
| 메모 | text | 선택 | 참고 메모 | 자유 텍스트 |
| 활성 상태 | boolean | 자동 | 재원/퇴원 구분 | 기본값: true(재원) |

- **테이블 형태**로 전체 학생 표시

- **반별 필터링**: 드롭다운으로 특정 반만 필터
- **이름 검색**: 실시간 검색
- **활성/비활성 필터**: 재원생/퇴원생 구분
- **학생 추가 버튼**: 우측 상단
- 행 클릭 → 학생 상세 페이지로 이동

### 3.3 반(클래스) 관리

#### 3.3.1 반 등록 항목

| 필드 | 필수 여부 | 설명 |
|------|-----------|------|
| 반 이름 | **필수** | 예: 중등 A반, 고등 심화반 |
| 설명 | 선택 | 수업 요일, 시간 등 참고 정보 |

#### 3.3.2 반 관리 화면

- 반 목록을 **카드 형태**로 표시
- 각 카드에 반 이름, 설명, 소속 학생 수 표시
- 카드 클릭 → 반 상세 (소속 학생 목록)
- 반에서 학생 추가/제거 기능
- **학생은 여러 반에 동시 소속 가능** (다대다 관계)
- **반에 소속되지 않은 학생도 존재 가능** (유연한 구조)

#### 3.3.3 반 단위 일괄 작업

- 반 전체 학생에게 과제 일괄 배정
- 반 전체 학생 점수 일괄 입력

### 3.4 단어장 관리

#### 3.4.1 단어장 등록

**등록 항목:**

| 필드 | 필수 여부 | 설명 |
|------|-----------|------|
| 단어장 제목 | **필수** | 예: "중등 필수 영단어 Day 1~10" |
| 설명 | 선택 | 참고 설명 |
| CSV 파일 | **필수** | 단어 데이터가 담긴 CSV 파일 |

**CSV 파일 형식:**

```csv
english,korean
apple,사과
accomplish,"성취하다, 달성하다"
abbreviation,약어
```

- 첫 행: 헤더 (`english,korean`) - 필수
- 인코딩: **UTF-8** (한글 깨짐 방지)
- 한글 뜻에 쉼표가 포함될 경우 큰따옴표로 감싸기
- 업로드 후 **미리보기 화면**에서 데이터 확인 → 최종 등록

**CSV 업로드 플로우:**

```
[단어장 제목/설명 입력]
    ↓
[CSV 파일 선택 (드래그앤드롭 또는 파일 선택)]
    ↓
[미리보기 테이블 표시]
  - 총 N개 단어 인식됨
  - 번호 | 영어 | 한글 형태로 미리보기
  - 오류 행이 있으면 하이라이트 표시
    ↓
[확인 후 '등록' 버튼 클릭]
    ↓
[단어장 + 단어들 DB에 저장]
    ↓
[단어장 상세 페이지로 이동]
```

#### 3.4.2 단어장 목록 화면

- **카드 형태** 목록
- 각 카드: 단어장 제목, 설명, 단어 수, 등록일
- 검색 기능 (제목 검색)
- 카드 클릭 → 단어장 상세

#### 3.4.3 단어장 상세 페이지

```
+------------------------------------------+
| ← 뒤로   중등 필수 영단어 Day 1~10  편집  |
|           총 30개 단어                     |
+------------------------------------------+
| [단어 추가] [순서 변경 모드]               |
+------------------------------------------+
| # | 영어            | 한글              |⋯|
|---|-----------------|-------------------|--|
| 1 | apple           | 사과              |✎🗑|
| 2 | accomplish      | 성취하다           |✎🗑|
| 3 | abbreviation    | 약어              |✎🗑|
| ...                                      |
+------------------------------------------+
```

- 단어 테이블: 번호, 영어, 한글, 수정/삭제 액션
- **개별 단어 수정**: 인라인 편집 또는 모달
- **개별 단어 삭제**: 확인 후 삭제
- **단어 추가**: 상단 버튼 → 영어/한글 입력 모달
- **순서 변경**: 드래그앤드롭 또는 번호 직접 수정
- **단어장 정보 수정**: 제목, 설명 수정

### 3.5 시험지 생성 및 출력

> **이 기능이 핵심 기능이며, 기존 엑셀 VBA를 대체하는 가장 중요한 부분.**

#### 3.5.1 시험지 생성 플로우

```
[시험지 생성 페이지]
    ↓
[Step 1: 학생 선택]
  - 드롭다운 또는 검색으로 학생 선택
  - 복수 학생 선택 가능 (같은 시험지를 여러 학생 이름으로)
    ↓
[Step 2: 단어장 선택]
  - 드롭다운으로 단어장 선택
    ↓
[Step 3: 시험 유형 선택]
  - ○ 영어 → 한글 (영어 단어를 보고 한글 뜻 작성)
  - ○ 한글 → 영어 (한글 뜻을 보고 영어 단어 작성)
    ↓
[Step 4: 옵션 설정]
  - 랜덤 셔플: ON / OFF (기본: OFF)
  - 출제 범위: 전체 / 특정 범위 (예: 1번~30번)
  - 문항 수 제한: 전체 / N문항 (랜덤 추출)
    ↓
[미리보기 생성 버튼]
    ↓
[시험지 미리보기 화면]
  - 실제 인쇄될 모습 그대로 화면에 표시
  - 'PDF 다운로드' 버튼
  - '바로 인쇄' 버튼 (브라우저 인쇄)
    ↓
[인쇄 또는 다운로드 실행]
    ↓
[test_records 테이블에 출력 기록 자동 저장]
```

#### 3.5.2 시험 유형 상세

| 유형 | 출제 방식 | 시험지 형태 |
|------|-----------|------------|
| **영 → 한** | 영어 단어가 제시됨 | 왼쪽: 영어 단어 / 오른쪽: 빈 답란 (한글 뜻 작성) |
| **한 → 영** | 한글 뜻이 제시됨 | 왼쪽: 한글 뜻 / 오른쪽: 빈 답란 (영어 단어 작성) |

#### 3.5.3 시험지 옵션 상세

| 옵션 | 설명 | 기본값 |
|------|------|--------|
| 랜덤 셔플 | 단어 순서를 랜덤으로 섞을지 여부 | OFF (원래 순서) |
| 출제 범위 | 전체 단어 또는 특정 번호 범위 | 전체 |
| 문항 수 제한 | 전체 출제 또는 N문항만 랜덤 추출 | 전체 |

### 3.6 점수 관리

### 3.7 과제 스케줄 관리

#### 3.7.1 스케줄 배정

**배정 방법:**
1. 캘린더에서 날짜 클릭 → 과제 배정 모달 열기
2. 학생 선택 (개별) 또는 반 선택 (일괄)
3. 단어장 선택
4. 메모 입력 (선택)
5. 저장

**스케줄 상태:**

| 상태 | 색상 | 설명 |
|------|------|------|

| 진행중 (in_progress) | 노랑 | 해당 날짜가 됨 (자동 전환 또는 수동) |
| 완료 (completed) | 초록 | 과제 완료 (선생님이 체크) |
| 미완료 (missed) | 빨강 | 기한 내 미완료 |

| printed_by | uuid | FK → profiles(id) | 출력한 사람 |
| printed_at | timestamptz | default now() | 출력 시간 |

### 4.3 ER 관계도 요약

```
academies ─┬─< profiles (1:N)
           ├─< classes (1:N)
           ├─< students (1:N)
           ├─< vocab_books (1:N)
           ├─< schedules (1:N)
           ├─< scores (1:N)
           └─< test_records (1:N)

classes >──< students (N:M, via class_students)

vocab_books ──< vocab_words (1:N)

students ──< scores (1:N)
students ──< schedules (1:N)
students ──< test_records (1:N)

vocab_books ──< scores (1:N)
vocab_books ──< schedules (1:N)
vocab_books ──< test_records (1:N)
```

### 4.4 RLS (Row Level Security) 정책

모든 테이블에 `academy_id` 기반 RLS 정책 적용:

| 작업 | 정책 |
|------|------|
| SELECT | `academy_id = (현재 로그인 유저의 academy_id)` |
| INSERT | `academy_id = (현재 로그인 유저의 academy_id)` |
| UPDATE | `academy_id = (현재 로그인 유저의 academy_id)` |
| DELETE | `academy_id = (현재 로그인 유저의 academy_id)` + `role = 'admin'` (관리자만 삭제 가능) |

**구현 방식:**
- `profiles` 테이블에서 현재 `auth.uid()`의 `academy_id`를 조회하는 헬퍼 함수 생성
- 모든 RLS 정책에서 이 함수를 활용하여 데이터 격리

### 4.5 인덱스 전략

| 테이블 | 인덱스 대상 | 이유 |
|--------|------------|------|
| profiles | academy_id | 학원별 유저 조회 |
| students | academy_id, is_active | 학원별 재원생 조회 |
| class_students | class_id, student_id | 반별 학생 조회 |
| vocab_words | vocab_book_id, sort_order | 단어장 내 정렬 조회 |
| scores | student_id, test_date | 학생별 날짜순 점수 조회 |
| scores | academy_id, test_date | 학원별 날짜 범위 조회 |
| schedules | academy_id, scheduled_date | 학원별 날짜 스케줄 조회 |
| schedules | student_id, scheduled_date | 학생별 스케줄 조회 |
| test_records | student_id, printed_at | 학생별 출력 이력 조회 |

## 부록: 용어 정의

| 용어 | 설명 |
|------|------|
| 멀티테넌트 (Multi-tenant) | 하나의 시스템으로 여러 학원(고객)이 독립적으로 사용하는 구조 |
| RLS (Row Level Security) | 데이터베이스 행 수준에서 접근 권한을 제어하는 PostgreSQL 기능 |
| SaaS (Software as a Service) | 웹을 통해 소프트웨어를 서비스 형태로 제공하는 모델 |
| CSV (Comma-Separated Values) | 쉼표로 구분된 텍스트 파일 형식 |
| slug | URL에 사용되는 읽기 쉬운 고유 식별자 (예: happy-english) |
| Server Actions | Next.js에서 서버 사이드 로직을 컴포넌트에서 직접 호출하는 기능 |
